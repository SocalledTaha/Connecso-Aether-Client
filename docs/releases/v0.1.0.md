# Connecso Aether Client 0.1.0

First public Android release of Connecso Aether Client.

- Full-device VPN connection through the Aether engine.
- Optional second-hop routing with subscription and manually pasted nodes.
- Per-app split tunneling, live connection notification, and home-screen widget.
- Subscription controls for refresh, automatic refresh intervals, active/default selection, editing, duplication, and removal.
- In-app release checks linked to the Connecso Aether Client repository.
- Updated Connecso launcher, notification, and Action Center icons.

The initial APK is built for Android `arm64-v8a` devices.
